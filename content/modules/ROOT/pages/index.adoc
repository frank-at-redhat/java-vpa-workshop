= Java Right-Sizing Workshop

This workshop is for platform engineers and Java application teams running
services on OpenShift who are fighting resource problems: OOMKills, CPU
throttling that looks like slowness, or nodes that are "full" at 30% use.
By the end, you can explain how the JVM reads container limits, stand up the
OpenTelemetry Java agent so JVM behavior is visible, and use the Vertical Pod
Autoscaler with in-place resize to right-size workloads without guessing.

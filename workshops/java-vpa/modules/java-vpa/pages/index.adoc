= Right-Sizing Java on OpenShift: VPA and OpenTelemetry

This workshop shows how to right-size Java workloads on OpenShift 4.22 using the
Vertical Pod Autoscaler (VPA) with in-place pod resize, and how to use the
OpenTelemetry Java agent to see what the JVM is actually doing before trusting
any recommendation.
After it, attendees can explain why Java needs special handling under VPA, stand
up the OpenTelemetry pieces that make JVM behavior visible, and choose a VPA
update mode per workload with confidence.

Before you start, make sure your environment meets the xref:setup-requirements.adoc[Setup Requirements].
